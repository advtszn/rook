---
title: Keyboard Shortcuts
description: Complete keyboard shortcut reference.
---

Rook uses vim-style keybindings across all screens.

## Global

| Key | Action |
|-----|--------|
| `j` / `↓` | Move down / scroll down |
| `k` / `↑` | Move up / scroll up |
| `g` | Jump to top |
| `G` | Jump to bottom |
| `q` / `Esc` | Go back / quit |

## Connections Screen

| Key | Action |
|-----|--------|
| `Enter` | Connect to selected |
| `a` | Add new connection |
| `i` | View connection info |
| `D` | Delete connection |

## Explorer Screen

| Key | Action |
|-----|--------|
| `h` / `←` | Navigate to parent |
| `l` / `→` / `Enter` | Expand namespace / open key |
| `/` | Search keys |
| `r` | Refresh key list |
| `R` | Toggle auto-refresh (5s / 10s / 30s / off) |
| `y` | Copy key name to clipboard |
| `D` | Delete key or namespace |

## Inspector Screen

| Key | Action |
|-----|--------|
| `j` / `k` | Scroll value |
| `h` / `←` / `q` / `Esc` | Back to explorer |
